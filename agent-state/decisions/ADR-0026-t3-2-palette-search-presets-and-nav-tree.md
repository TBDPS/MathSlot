## 2. 技术契约

### 2.1 `xtask` 与 `crates/mathslot-app` 契约扩展（`D-111`、`D-112`）
1. **`xtask` 生成 `packages/ui/src/generated/presets.ts`**：
   - 解析 `catalog/presets.json`，生成只读文件 `packages/ui/src/generated/presets.ts`（首行 `// @generated by xtask. DO NOT EDIT.`），导出 `PresetEntry`、`PRESETS`（88 条）、`PRESET_CATEGORIES`（9 分类）。
   - 更新 `xtask/src/main.rs` 使 `cargo run -p xtask -- check` 同时校验这 6 份产物无 diff（CI 一致）。
2. **`D-111`（槽位层次路径与直跳事件）**：
   - `SlotSnapshot` 增加 `path: Vec<usize>` 与 `depth: usize`（直接取自 `mathslot_doc::Slot.path`）。
   - `AppEvent::SelectSlot(u32)` → 调用 `editor.nav_to_slot(SlotId(id))` → 发出 `Effect::Focus(FocusTarget::Slot(SlotId(id)))` 与状态消息，不改变文本与撤销历史（`A-EDIT-008`）。
   - `App::sync_state` 在 `is_nav_mode()` 时将当前活动槽位面包屑/索引路径填入 `EditorState::Nav { path }`，不再固定为空向量。
3. **`D-112`（88 条内置预置流式载入）**：
   - `AppEvent::LoadStreamSource(String)` → 通过 `mathslot_doc::Editor` 解析流式简码并原子替换文档内容（`Render` + `Status` Effect，不破坏撤销或静默吞错）。

### 2.2 `packages/ui` 组件与视觉/可访问性契约（`T3.2`）
1. **调色板与命令/预置搜索（`PalettePanel.svelte`）**：
   - **唯一事实源**：直接消费 `generated/catalog.ts`（121 条命令、8 个分类）与 `generated/presets.ts`（88 条预置、9 个分类），严禁手写第二份命令或预置数组（`D-001` 5 张核心卡片 `oc/xb/og/of/xa` 100% 由 `catalog.ts` 渲染）。
   - **视觉呈现**：采用与 `tokens.css` 明/暗双主题完全适配的现代卡片网格、清晰按键徽章（`<kbd>` 渲染 `▸`+keys）、悬停/选中边框与 `:focus-visible` 焦点环（WCAG AA 对比度），无硬编码深色块（`D-026`）。
   - **交互与键盘可达性（`A-EDIT-004`, `D-015`, `A-UI-001`）**：
     - 搜索框支持即时模糊匹配 `label`、`keys`、`id`、`latex`、`doc`；
     - 分类 `role="tablist"` 与卡片网格支持键盘移动焦点 / 选中与 `Enter`/`Space` 激活；
     - 激活命令卡片调用 `client.dispatch({ ApplyCard: cmd.id })` 并触发 `onRequestEditorFocus?.()` 回调（仅在点击/激活回调执行一次，绝不轮询）；激活预置卡片调用 `client.dispatch({ LoadStreamSource: preset.source })`。
2. **可滚动结构化导航树（`NavTreePanel.svelte`）**：
   - **可滚动树与溢出处治（`D-008`, `D-020`, `A-RENDER-002`, `A-UI-003`, `S-003`, `S-004`）**：
     - 基于 `SlotSnapshot.path` / `depth` 构建树节点缩进与分组（如 3×3 矩阵 9 槽位、嵌套分数/根号），置于带 `overflow-y: auto` 与合理高度约束的容器内，节点与徽章分区渲染、互不遮挡溢出。
     - 支持 `role="tree"` / `role="treeitem"`、`aria-expanded`、`aria-current="step"` 与槽位状态文字标注（“空槽位”/“已填”，不只靠颜色）。
     - 支持 `ArrowUp`/`ArrowDown` 移动、点击或 `Enter`/`Space` 派发 `SelectSlot(slot.id)`，以及切换导航模式 `EnterNavMode`/`ExitNavMode`。

## 3. TDD 验收标准（先红后绿）

1. **Rust TDD（`crates/mathslot-app` + `xtask`）**：
   - 先写失败测试覆盖 `SlotSnapshot.path/depth`、`SelectSlot(id)`、`Nav { path }`、`LoadStreamSource`；观察红后实现并运行 `cargo run -p xtask -- generate` 与 `cargo run -p xtask -- check`。
2. **前端 TDD（`packages/ui/tests/`）**：
   - 先写 `palette.test.ts` 与 `navTree.test.ts`（运行观察 FAIL）再实现组件：
     - 渲染 `121` 条命令全部与 `COMMANDS` 一致（包含 `D-001` 5 张卡片 `partial/oc/∂`），点击/回车“偏导”发送 `ApplyCard: "partial"`；
     - 命令搜索（`偏导` / `oc` / `frac`）与 8 分类切换过滤结果准确，88 条内置预置可搜索并点击发送 `LoadStreamSource`；
     - 调色板与导航树全键盘可达（`Tab` / 方向键 / `Enter` / `Space`），ARIA role 与对比度语义齐全；
     - 3×3 矩阵（9 槽位）与深度嵌套结构（depth ≥ 3）导航树呈分层可滚动列表（无固定高裁切），选中槽位发送 `SelectSlot(id)`。

   - `cargo clippy --workspace --all-targets -- -D warnings` PASS
   - `cargo test --workspace --offline` PASS（`0 failed; 0 ignored`）
   - `cargo run -p xtask -- check` PASS
   - `scripts/agent/audit_palette.py` PASS
   - `cd packages/ui && npm test && npm run check && npm run build` PASS
