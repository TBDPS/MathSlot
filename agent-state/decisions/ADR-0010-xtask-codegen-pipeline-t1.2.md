# ADR-0010：建立 xtask 代码生成管线与 5 大产物单一事实源落地（T1.2）

- 日期：2026-11-13
- 状态：已批准
- 决策者：coordinator（依据 `AUD-7` 审计结论与规范 §8.2、§8.3、§14 G1 / T1.2）
- 关联任务：`T1.2`
- 关联不变量：`INV-001`, `INV-006`, `INV-015`

## 1. 背景与依据

- 规范 §14 Gate G1（单一事实源）任务：
  > T1.2 | 生成调色板/文档/TS 类型 | T1.1 | xtask + generated | 生成文件可重复、无 diff
- 规范 §8.2：构建时由 `xtask` 根据 `catalog/commands.toml` 生成 5 大产物，禁止手改：
  1. `crates/mathslot-command/src/generated.rs`（Rust 运行时静态常量表）
  2. `catalog/catalog.json`（WASM / TS / Obsidian 消费的完整元数据）
  3. `docs/commands.md`（供 README / HELP 引用的标准命令文档）
  4. `packages/ui/src/generated/catalog.ts`（Svelte / Web 前端类型与字典）
  5. `schemas/commands.schema.json`（JSON Schema 契约校验文件）
- `AUD-7` 审计确认：`xtask` 尚未建立，各生成文件尚未产出。需建立确定性生成工具链与 CI/单测比对机制。

## 2. 决策内容

### 2.1 xtask 架构与 Workspace 集成

1. 在仓库根目录下设立 `xtask/`：
   - `xtask/Cargo.toml`：依赖 `mathslot-command`、`serde_json`、`toml`。
   - `xtask/src/main.rs`：提供 CLI 子命令 `codegen`（执行全量生成）与 `check`（检查生成内容是否与磁盘文件一致，若有 diff 则返回非零）。
2. 在根 `Cargo.toml` 的 `workspace.members` 中添加 `"xtask"`。

### 2.2 确定性生成保障机制

为确保在不同平台、不同构建环境下生成结果可 100% 重复且 `git diff --exit-code` 为 0：
1. **稳定排序**：所有遍历与输出按 `category` 与 `id`（或按键序列）字典序稳定排序；
2. **统一换行**：统一采用 LF (`\n`) 换行；
3. **安全路径创建**：写出前调用 `fs::create_dir_all` 自动创建各产物的目标父目录；
4. **禁止手改警示头**：每个生成文件头部均注入统一警示注释（如 `// @generated by xtask. DO NOT EDIT.` 或 `<!-- @generated by xtask. DO NOT EDIT. -->`）。

### 2.3 树内测试守护 (In-Tree Codegen Guard Test)

在 `crates/mathslot-command/tests/codegen_tests.rs` 中编写单元测试：
- 调用生成器逻辑或比对磁盘上 5 个生成文件的现有内容与根据 `catalog/commands.toml` 最新生成的内容；
- 断言两者内容 100% 相同；若开发者手动修改了生成文件而未更新 `commands.toml`，测试自动拦截失败。

### 2.4 范围与约束

- 允许修改/新增路径：
  - `xtask/**`
  - `crates/mathslot-command/src/generated.rs`
  - `crates/mathslot-command/src/lib.rs`（声明 `pub mod generated;`）
  - `crates/mathslot-command/tests/codegen_tests.rs`
  - `catalog/catalog.json`
  - `docs/commands.md`
  - `packages/ui/src/generated/catalog.ts`
  - `schemas/commands.schema.json`
  - `Cargo.toml`（仅追加 `"xtask"`）
  - `Cargo.lock`
- 严禁修改其他现有业务逻辑。

## 3. 验收要求（VER-7）

1. 5 大生成产物全部存在，结构符合规范 §8.2 契约；
2. `cargo run -p xtask -- check`（或树内测试）：exit 0，生成文件无任何 diff；
3. `cargo fmt --check`：exit 0
4. `cargo clippy --workspace --all-targets -- -D warnings`：exit 0
5. `cargo test --workspace`：全部通过（原有 146 passed + 新增 codegen 测试）。
6. 提交信息：`T1.2: implement xtask codegen pipeline and generate 5 catalog artifacts`
