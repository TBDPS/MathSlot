# ADR-0036: T4.5 生成文档（README / HELP / 架构 / 插件文档）与唯一事实源零漂移门禁

- **日期**：2026-11-15
- **Gate / Task**：`G4` / `T4.5`
- **状态**：Approved（待实现与独立验收）
- **依据审计**：`agent-state/audits/AUD-32.md`（覆盖 `D-162`..`D-166`，彻底关闭 `D-002` 与 `D-022` 文档滞后问题）

---

## 1. 上下文与阻塞事实

[AUD-32.md](../audits/AUD-32.md) 核查发现当前仓库虽然具备 `xtask`（生成 6 份基础产物），但用户与工程活动文档仍存在实质性失实与事实源分叉（判定 **BLOCK**）：

1. **`D-162`（P1）**：`README.md` 与 `HELP.md` 未接入 `<!-- BEGIN GENERATED: ... -->` / `<!-- END GENERATED: ... -->` 生成块，命令清单为纯手写：`README.md` 仅列 `29/121` 条、`HELP.md` 仅列 `101/121` 条且漏列 20 个希腊字母，**`HELP.md:176` 将 `▸gx` 错写为 `\Delta`、`▸gz` 错写为 `\Omega`**（catalog 实为 `\xi` 与 `\zeta`），并含 10 处已失效的幻影指令（`▸j`, `▸jcb`, `▸ka..▸kz`, `▸td`, `▸m`）。
2. **`D-163`（P1）**：`README.md` 与 `HELP.md` 架构、交互、规模、Schema 与路径严重滞后（仍描述 `eframe/egui`、旧 `Tab` 触发、`F1` 帮助面板、`60+ / 6 大领域`、`schema_version: 1` 及错误 macOS `~/.config` 回退，实际为 Tauri 2 `apps/desktop` + Obsidian `apps/obsidian` + `packages/ui` CM6/MathJax、`88 条 / 9 大分类`、`CURRENT_LIBRARY_SCHEMA_VERSION = 3`）；`README.md:4` `[License](LICENSE)` 死链、`README.md:202` 指向历史 Round 8 决策报告。
3. **`D-164`（P2）**：缺失独立的 `obsidian-mathslot/README.md` 与当前版架构文档 `docs/ARCHITECTURE.md`；版本号/命令数/预置数/Schema 版本分散手写，未由 `xtask` 注入。
4. **`D-165`（P2）**：`xtask` 未管理 `README.md`/`HELP.md` 等活动文档生成块；`crates/mathslot-command/tests/codegen_tests.rs` `ARTIFACT_PATHS` 遗漏 `presets.ts`，且未校验活动文档内全部 `▸xx` 均可由 `mathslot_syntax::parse` 解析、`README.md`/`HELP.md` 在生成块外无手写命令表以及相对链接有效；`.github/workflows/ci.yml` 缺重生成 `git diff --exit-code` 校验；`scripts/agent/acceptance.sh` 未调用 `xtask --check`。
5. **`D-166`（P2）**：`PalettePanel.svelte:168,182` 将 `(121)` 与 `(88)` 标签计数硬编码，未绑定 `{COMMANDS.length}` 与 `{PRESETS.length}`；`HELP.md:414` 虚假声称 UI 存在 `F1` 帮助面板。

## 2. 决策方案

### 2.1 `xtask` 扩展为唯一文档生成器（`D-162`, `D-164`）

扩展 `xtask/src/codegen.rs` 与 `xtask/src/main.rs`（纯离线、`serde_json`/`toml` + Rust 标准库），除既有 6 份产物外，为以下 **4 份活动文档** 提供确定性**锚点块注入（`<!-- BEGIN GENERATED: <name> -->` ... `<!-- END GENERATED: <name> -->`）**与 `--check` 全量字节对比校验：

1. **注入源统一读取**：
   - 命令：`catalog/commands.toml` -> `CommandCatalog`
   - 预置：`catalog/presets.json` -> `PresetsFile`（88 条、9 大分类及统计）
   - 元数据：直接解析工作区 `Cargo.toml`（`workspace.package.version` / `license`）、`obsidian-mathslot/manifest.json`（Obsidian 插件版本）、`crates/mathslot-store/src/lib.rs` 的 `CURRENT_LIBRARY_SCHEMA_VERSION` 与默认快捷键定义（与 `mathslot-store`/`shortcuts.ts` 保持同一事实源，无硬编码版本/Schema/快捷键）。
2. **受控生成块范围**：
   - `README.md`：
     - `<!-- BEGIN GENERATED: metadata -->` ... `<!-- END GENERATED: metadata -->`（版本、授权、命令总数/分类数、预置总数/分类数、配置 Schema 版本）
     - `<!-- BEGIN GENERATED: commands -->` ... `<!-- END GENERATED: commands -->`（**完整 121 条命令目录**，使用干净 Markdown 表格/折叠 `<details>` 直接由 `docs/commands.md` 同源生成函数输出，保证 `README.md` 满足 §8.5“全量由 `commands.md` 同源注入、标记块外零手写命令表、每条命令至少出现一次”）
     - `<!-- BEGIN GENERATED: presets -->` ... `<!-- END GENERATED: presets -->`（9 大预置分类统计与示例）
     - `<!-- BEGIN GENERATED: shortcuts -->` ... `<!-- END GENERATED: shortcuts -->`（工作区可配置默认快捷键与导航按键真值表）
   - `HELP.md`：
     - `<!-- BEGIN GENERATED: metadata -->` ... `<!-- END GENERATED: metadata -->`
     - `<!-- BEGIN GENERATED: commands -->` ... `<!-- END GENERATED: commands -->`（**完整 121 条命令按 8 大分类生成**，彻底消除 `HELP.md:176` 错误希腊字母映射与 10 处幻影指令）
     - `<!-- BEGIN GENERATED: presets -->` ... `<!-- END GENERATED: presets -->`
     - `<!-- BEGIN GENERATED: shortcuts -->` ... `<!-- END GENERATED: shortcuts -->`
   - `obsidian-mathslot/README.md`（新建插件用户/构建文档）：
     - 包含 `<!-- BEGIN GENERATED: metadata -->`、`<!-- BEGIN GENERATED: shortcuts -->` 与同步的 `▸` 命令语法/目录入口，说明 Obsidian `MarkdownRenderer.renderMath` 优先 + MathJax 3 SVG 回退、WASM 沙箱架构与构建验证流程。
   - `docs/ARCHITECTURE.md`（新建当前版架构权威文档）：
     - 精确描绘当前多端共享架构（`crates/mathslot-{syntax,doc,latex,command,app,store,render,wasm}`、`packages/ui` CM6/Svelte 5、`apps/desktop` Tauri 2、`apps/obsidian` 插件 + `xtask` 代码生成流），并包含 `<!-- BEGIN GENERATED: metadata -->` 注入的工作区包与产物清单统计。
   - 同时确认 `packages/ui/src/generated/presets.ts` 包含标准的 `// @generated by xtask. DO NOT EDIT.` 头注释，并纳入统一校验。

### 2.2 活动文档真实性与边界清理（`D-163`, `D-166`）

1. **对齐真实代码与交互**：
   - 重写 `README.md` 与 `HELP.md` 的手写叙述，彻底清除过期 `egui / eframe`、`460px 左栏三框`、`📖 示例公式库`、`↻ 换一个`、旧 `Tab` 插入 `▸`、`Tab j` / `Alt j`、`[k▸]`/`[t▸]`、ASCII 简写自动替换、`schema_version: 1`、macOS `~/.config` 回退以及 **虚假 `F1` 帮助面板声明**。
   - 按 `AGENTS.md` 硬规则 8（新功能冻结），**不在 `T4.5` 新增未授权的 `F1` 帮助弹窗 UI**，而是让 `HELP.md` 真实描述当前共享 UI 功能（`PalettePanel` 可搜索命令目录与预置公式、可配置 `Mod+J` / `Mod+E` / `Mod+,` / `Mod+Shift+C` / `Mod+Shift+S`、`SettingsPanel` 快捷键自定义与三平台存储路径 `paths.rs`）。
   - 修复断链与历史依赖：移除 `README.md` 无效相对链接 `[License](LICENSE)`（改用 `Cargo.toml` 权威声明的 `MIT OR Apache-2.0` 文本标注，不新增未经授权的法律文件），并将对历史 Round 8 报告的外链替换为活动文档链接（`HELP.md`、`docs/commands.md`、`docs/ARCHITECTURE.md`、`obsidian-mathslot/README.md`）。
   - 保持 `docs/AUDIT_*.md`、`docs/ACCEPTANCE_*.md`、`docs/DECISION_*.md` 等 48 份历史归档报告只读不改。
2. **UI 动态计数消除硬编码（`D-166`）**：
   - `packages/ui/src/palette/PalettePanel.svelte:168,182` 将硬编码 `命令目录 (121)` 与 `预置公式 (88)` 改为动态读取 `{COMMANDS.length}` 与 `{PRESETS.length}`。
3. **跨 Gate 边界声明（避免越界）**：
   - `scripts/install-desktop.sh`、`assets/mathslot.desktop` 与 `.github/workflows/release.yml` 属于 **`T4.6`（发布流水线与原生桌面打包）** 范围，不在 `T4.5` 修改；`T4.5` 原位修正根目录 `README.md` 与 `HELP.md` 已可立即消除旧文档内容本身的问题。

### 2.3 全链路可解析性与零漂移测试/CI 门禁（`D-165`）

1. **`crates/mathslot-command/tests/codegen_tests.rs`（及必要集成测试）增强**：
   - 将 `packages/ui/src/generated/presets.ts` 加入 `ARTIFACT_PATHS` 校验存在性、LF、单末尾换行与 `@generated` 标头。
   - 检验 `README.md`、`HELP.md`、`obsidian-mathslot/README.md`、`docs/ARCHITECTURE.md`、`docs/commands.md` 中所有标记块成对合法，且执行与 `xtask` 同源检查无任何手工篡改/漂移。
   - **禁止标记块外手写命令表**：校验 `README.md` 与 `HELP.md` 在 `<!-- BEGIN GENERATED: commands -->` ... `<!-- END GENERATED: commands -->` 之外不存在多列表格形式的命令清单，且全 121 条 catalog 命令均出现在 `docs/commands.md`、`README.md` 与 `HELP.md` 中。
   - **真实解析器校验（`D-002` / §8.3）**：扫描所有活动文档（`docs/commands.md`、`README.md`、`HELP.md`、`obsidian-mathslot/README.md`）中的每个 `▸<ident>` token，确认均存在于 `CommandCatalog` 且由 `mathslot_syntax::parse`（在测试通过 Workspace crate `mathslot-syntax` 或与 catalog 联动校验，注：`mathslot-command` 的 `[dev-dependencies]` 若不引入循环依赖即可引入 `mathslot-syntax` 或将解析校验放在 `mathslot-syntax` / 独立集成测试 `crates/mathslot-syntax/tests/` 或 `crates/mathslot-app/tests/`）零诊断错误通过解析。
   - **相对链接有效性**：检验上述活动文档内全部相对 Markdown 链接 `[...](path)` 均指向仓库真实存在的文件，零死链。
2. **`.github/workflows/ci.yml` 增强**：
   - 在 CI 既有 `cargo run -p xtask -- check` 之后追加 `cargo run -p xtask -- generate && git diff --exit-code` 验证幂等再生零漂移。
3. **工具链独立提交（coordinator 执行）**：
   - 按照 `AGENTS.md` §2 权限隔离，coordinator 将在独立工具链提交中把 `cargo run -p xtask -- check` 接入 `scripts/agent/acceptance.sh`。

## 3. 允许写入范围（`T4.5` 严格限定）

实现者（`mathslot-implementer`）仅允许修改或新增以下路径，且**只能产出一个原子提交**（commit message 含 `T4.5` 与 `D-162 D-163 D-164 D-165 D-166 D-002 D-022`）：

- `xtask/**`
- `crates/mathslot-command/**`（仅 `tests/` 与由 `xtask` 自动生成/检查的 `src/generated.rs`；无功能变更）
- `crates/mathslot-syntax/tests/**` 或 `crates/mathslot-app/tests/**`（若用于 `mathslot_syntax::parse` 对活动文档全部 `▸xx` 做闭环解析校验且避免 Cargo 循环依赖）
- `packages/ui/src/palette/PalettePanel.svelte` & `packages/ui/src/generated/**` & `packages/ui/tests/**`
- `README.md`、`HELP.md`、`docs/commands.md`、`docs/ARCHITECTURE.md`、`obsidian-mathslot/README.md`
- `.github/workflows/ci.yml`
- 若 `packages/ui` 或文档改动触发 build hash 变化，需重跑 `node obsidian-mathslot/scripts/build.mjs` 保持 `obsidian-mathslot/` 零构建漂移

**严禁修改**：`docs/LLM_IMPLEMENTATION_SPEC.md`、48 份历史归档报告（`docs/AUDIT_*`/`docs/ACCEPTANCE_*`/`docs/DECISION_*`/`docs/IMPLEMENTATION_*`/`docs/REWRITE_DESIGN.md`/`docs/reports/**`）、`scripts/agent/**`、`agent-state/**`、`scripts/install-desktop.sh`、`assets/mathslot.desktop`、`.github/workflows/release.yml`。

## 4. 验收标准

1. **Red -> Green TDD**：先在测试中复现缺失 `README.md`/`HELP.md` 生成块、`▸gx`/`▸gz` 错映射、未知 `▸j` 等幻影指令、`presets.ts` 漏检、`LICENSE` 死链及 `PalettePanel` 硬编码计数；再落地实现并展示全部通过。
2. **全量验证必绿**：
   - `cargo run -p xtask -- check`（覆盖 6 份生成物 + 4 份活动文档注入块，exit 0）
   - 幂等校验：`cargo run -p xtask -- generate` 后 `git diff --exit-code` 为 0
   - `cargo fmt --check`、`cargo clippy --workspace --all-targets -- -D warnings`、`cargo test --workspace --offline`
   - `npm --prefix packages/ui test && npm --prefix packages/ui run check`
   - `npm --prefix apps/desktop test && npm --prefix apps/desktop run check && npm --prefix apps/desktop run build`
   - `npm --prefix apps/obsidian test && npm --prefix apps/obsidian run check && npm --prefix apps/obsidian run build`
   - `node obsidian-mathslot/scripts/build.mjs` 且 `git status --short` 零构建漂移
   - `scripts/agent/audit_palette.py`
