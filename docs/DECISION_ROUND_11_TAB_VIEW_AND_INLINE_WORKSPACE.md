# MathSlot UI/UX 架构革新与视觉设计蓝图
## 决策 Round 11：废除模态浮窗 · 右侧一等公民内联工作区体系（Inline Tab System）

**设计团队**：MathSlot 顶尖美术与 UI/UX 设计工作室  
**版本代号**：v0.8.0-blueprint (Round 11)  
**设计基准**：Linear & Raycast 极简微光系统、Apple Human Interface Guidelines、Tailwind Zinc 暗黑阶梯

---

## 一、 重构背景与核心痛点（Context & Problem Statement）

### 1.1 现状与用户诉求
在 MathSlot 此前的版本演进中，扩展中心、公式库、LaTeX 导入器以及帮助指南均采用居中弹出式浮窗（`egui::Window`）呈现。在最新的用户实测与深度交互中，用户提出了关键诉求：

> **“现在的语义表单会在中间空出一大块，我的建议是整个放弃新窗口的设计，改成直接在主界面的右侧显示，如同标签页一样，这样不会遮住右侧的预览框，可以观察载入效果。”**

### 1.2 浮窗模态的四大原罪（Visual & Ergonomic Flaws）
1. **遮挡关键视觉资产（预览视口盲区）**：
   弹窗居中弹出（高度 560~640pt，宽度 740~880pt），几乎完全覆盖了主工作区。当用户在公式库中浏览并点击“载入”某个复杂公式时，无法实时在左侧白纸预览框中看到公式排版效果，必须先关闭弹窗才能确认，交互动线严重断裂。
2. **表单横向空间撕裂与留白空洞**：
   浮窗采用固定宽度锁定后，卡片内部表单字段若采用固定列宽排布，在宽屏窗口下会在中间产生大面积无意义的灰色空洞；若拉伸字段，又导致简短字段（如触发字母、缩略提示）过度横向膨胀，比例失衡。
3. **视口跳变与视觉震颤**：
   不同弹窗之间尺寸不一（公式库 880px、扩展中心 780px、使用指南 740px），在不同弹窗之间切换时产生剧烈的窗口拉伸和重绘闪烁。
4. **快捷键与焦点歧义（Esc Ambiguity）**：
   浮窗模态下，`Esc` 键用于关闭弹窗；而在 MathSlot 主输入流中，`Esc` / `Tab j` 是核心的“槽位导航跳出/进入”键。模态浮窗引入了状态混淆与焦点迷失。

## 二、 架构革新：双翼工作流一体化（Unified Split Workspace）

我们将界面彻底从“主界面 + 弹出式模态遮罩”重构为**“双翼联动内联工作台”（Unified Split Workspace）**。所有的扩展功能不再作为二等公民的临时弹窗，而是全部升格为右侧工作区的一等公民标签页。

```
+----------------------------------------------------------------------------------------------------+
|  TOP BAR:  [Σ MathSlot v0.8.0] [模式 Badge] [槽位直达 Tab j] ... [公式库] [格式库] [⇄ 导入 LaTeX] [帮助] |
+-----------------------------------------------------+----------------------------------------------+
|  LEFT WING: 核心公式画板与输入流 (380~560pt)          |  RIGHT WING: 一等公民全功能工作区 (CentralPanel) |
|                                                     |                                              |
|  +-----------------------------------------------+  |  [ ∑ 符号结构 ] [ 📚 公式库 ] [ ⚙ 扩展中心 ]   |
|  | [框 1] 纯白白纸公式画布 (Paper Preview Box)      |  |  [ ⇄ LaTeX 导入 ] [ 💡 使用指南 ]            |
|  |  - 独立顶部 Header + 缩放控制 Toolbar (Zoom)   |  |  ------------------------------------------  |
|  |  - ScrollArea 双向平移视口                      |  |                                              |
|  |  - 实时毫秒级物理尺寸重绘                       |  |  ACTIVE TAB CONTENT AREA:                    |
|  +-----------------------------------------------+  |                                              |
|                                                     |  - 自适应 100% available_width 铺满          |
|  +-----------------------------------------------+  |  - 紧凑无空洞 3 层语义表单卡片               |
|  | [框 2] 槽位层级导航框 (Nav Structure Box)        |  |  - 全宽两段式公式卡片 / 结构网格 / 转换台   |
|  |  - 当前槽位深度、面包屑路径、子式直达            |  |  - 0px 窗口跳变，切换如丝般平滑              |
|  +-----------------------------------------------+  |                                              |
|                                                     |                                              |
|  +-----------------------------------------------+  |                                              |
|  | [框 3] 极简流输入与输出框 (Input & Output Box)    |  |                                              |
|  |  - 简码输入框 (带语法着色与光标同步)            |  |                                              |
|  |  - 快捷操作按钮组 + LaTeX / Typst 复制           |  |                                              |
|  +-----------------------------------------------+  |                                              |
+-----------------------------------------------------+----------------------------------------------+
|  STATUS BAR: 状态反馈信息、语法诊断提示与快捷键信号微文案 (Zinc-900 / 28pt)                           |
+----------------------------------------------------------------------------------------------------+
```

### 2.1 架构革新三大支柱
1. **彻底废除 `egui::Window`**：
   代码中不再声明任何浮动窗口实体，彻底杜绝窗口遮罩、层级穿透、拖拽偏移与视口跳变；
2. **“即点即显”心流闭环（Live Instant Feedback Flow）**：
   用户在右侧公式库点击任一公式的“载入”，左侧预览框在同一渲染帧内立即呈现出排版结果；在右侧 LaTeX 导入框粘贴代码，左侧立即重绘，眼动距离减半，无需往返关闭窗口；
3. **焦点平滑回归机制**：
   无论在右侧执行插入符号、载入公式、保存模版还是导入代码，完成后光标与焦点通过 `request_input_focus = true` 平滑归还左侧输入框，支持无缝键盘连续输入。

## 三、 右侧主标签页体系（Main Tab System）深度规范

右侧由顶部统一的**一级分段导航器（Segmented Navigation Bar）**驱动，划分五大功能工作区：

```rust
#[derive(Clone, Copy, Debug, PartialEq, Eq, Default)]
pub enum WorkspaceTab {
    #[default]
    Palette,     // 1: 符号与数学结构网格
    Corpus,      // 2: 权威公式库 (88+ 经典公式与自建库)
    Formats,     // 3: 扩展中心 (自定义宏与复用片段)
    LatexImport, // 4: LaTeX 逆向反编译工作台
    Help,        // 5: 使用指南与快捷键图谱
}
```

### 3.1 顶部一级分段导航器（Segmented Navigation Bar）
- **尺寸与排布**：
  - 高度：`38.0 pt`，贴顶横跨右侧 `CentralPanel` 通栏；
  - 容器外框：底色 `PANEL`（Zinc-900），底部发丝描边 1px `BORDER_SOFT`；
  - 内嵌 5 联胶囊（Segmented Pill），元素间距 `4.0 pt`。
- **胶囊状态视觉阶梯**：
  - **未激活（Idle）**：文字 `TEXT_DIM`（Zinc-400，12.5pt），透明背景；悬停时底色微亮为 `CARD`（Zinc-850），文字转为纯净白 `TEXT`；
  - **激活态（Active）**：底色高亮为 `CARD_HI`（Zinc-800），1px `BORDER` 精细描边，底部带有 2px 电光蓝 `ACCENT`（#3B82F6）指示光条，文字加粗 `strong()`；
  - **快捷键徽章（Badge）**：每个标签文字右侧带有克制的暗色键位微标签（如 `Alt+1` ~ `Alt+5`），提供视觉信号指引。

---

### 3.2 Tab 1: 符号结构 (Palette)
- **定位**：高频数学结构、常用符号与矩阵模板的直观网格陈列。
- **布局动线**：
  1. **分类胶囊行**：保持高密度的子分类胶囊（常用、微积分、分式根号、矩阵、希腊、逻辑、箭头、括号集合、标点重音），与键盘 `Tab` 敲入的前缀子菜单字母毫秒级智能同步高亮；
  2. **自适应磁贴网格（Tile Grid）**：
     - 利用 `ui.available_width()` 自动计算行列数，单卡尺寸 `min_width: 82.0 pt`，高度 `56.0 pt`；
     - 卡片底色 `CARD`，1px `BORDER_SOFT`，圆角 `8.0 pt`；
     - 卡片内光学居中：顶部展示微小徽标（如 `★/` 或 `Tab f /`，颜色 `AMBER` 或 `TEXT_DIM`），中部为巨型数学符（22pt，纯白 `TEXT`），底部为 11pt 克制中文标签。

---

### 3.3 Tab 2: 权威公式库 (Corpus)
- **定位**：88+ 权威预置公式浏览、检索、自建、导入与一键载入。
- **消除留白空洞的表单重构**：
  - 放弃弹窗中突兀的横向稀疏表单，采用**内联手风琴折叠卡片（Drawer Card）**：
    - **Header 栏（32pt）**：左侧检索栏（占宽 260pt，带清空图标）、分类下拉/滑动胶囊（全部、微积分、代数、物理、概率、几何等）、右侧按钮组（`+ 新建公式`、`恢复默认`、`JSON 导入/导出`）；
    - **新建/编辑表单（折叠抽屉）**：
      - *第 1 层（语义元信息）*：公式名称（占宽 35%） + 学科分类（占宽 25%） + 标签分类（占宽 40%），整行 100% 紧密铺满；
      - *第 2 层（核心载荷）*：简码源码输入框，独占整行通栏 100% `available_width`，等宽字体 `FIELD` 凹槽，底色 `rgb(12, 13, 18)`，无多余左右留白；
      - *第 3 层（描述与保存）*：公式说明输入框（占宽 80%） + 保存按钮（占宽 20%，翠绿强调），紧凑有力。
- **通栏两段式公式卡片列表（Full-Width Formula Rows）**：
  - 卡片 100% 通栏铺满，行高紧凑（`56.0 pt`），圆角 `8.0 pt`；
  - **左侧 65% 内容区**：中文公式名称（13.5pt，强对比纯净白）、学科标签徽章（微光胶囊）、简码语法高亮预览（等宽字体代码体）、公式说明；
  - **右侧 35% 动作区**（物理隔离，右对齐）：
    - `[ 载入到编辑器 (替换) ]`：Emerald-500 翠绿强调按钮，**点击后左侧预览框毫秒级重绘该公式**；
    - `[ 追加 ]`：将公式无缝拼接到当前简码后；
    - `[ 复制简码 ]` / `[ 复制 LaTeX ]`；
    - `[ 编辑 / 删除 ]`（针对用户自建项）。

---

### 3.4 Tab 3: 扩展中心 (Formats)
- **定位**：无需修改 Rust 源码，自由扩展任意 LaTeX 宏语法（`Tab k`）与管理片段模版库（`Tab t`）。
- **二级分段选择器**：`[ 自定义 LaTeX 格式 (k) ]`  `[ 用户复用片段 (t) ]`。
- **功能精炼，去粗取精（果断砍掉冗余陈旧输入）**：
  - 剔除无实际价值的“函数别名”、“陈旧内部标识”；
  - **自定义格式 3 层语义表单（严禁中间空洞）**：
    - *第 1 层（紧凑元信息）*：
      - 触发按键（`custom_key`: 48pt，单字母等宽，如 `g`）
      - 格式名称（`custom_label`: 160pt，如 `同余式`）
      - 缩略提示（`custom_glyph`: 96pt，如 `a≡b(m)`）
      - 槽位角色（`custom_roles`: 弹性铺满剩余宽度，如 `左项;右项;模数`）
    - *第 2 层（LaTeX 模板）*：
      - 独占整行 100% 通栏宽度，等宽代码字体，如 `$1 \equiv $2 \pmod{$3}`；
    - *第 3 层（操作行）*：
      - 快捷帮助文案 + `[ ✓ 保存格式 ]` 与 `[ 取消 ]`。
  - **列表行规范**：
    - 全宽凹槽行，左侧徽章展示 `Tab k + 键位`，中间显示中文名称与槽位参数，右侧固定 120pt 操作区（`编辑`、`删除`、`测试插入`）。

---

### 3.5 Tab 4: LaTeX 导入 (LatexImport)
- **定位**：从学术论文、网页或课件中复制的标准 LaTeX 表达式，一键逆向反编译为 MathSlot 简码流。
- **双向对照工作台布局**：
  1. **上部：原生 LaTeX 源码输入区**：
     - 通栏多行编辑框（高度 110pt），自适应铺满右侧视口；
     - 支持直接粘贴任何标准 LaTeX 语法（包含 `\frac`, `\sqrt`, `\int`, `\begin{pmatrix}` 等）；
  2. **中部：语法诊断与反编译状态条**：
     - 绿色勾选表示“100% 无损反编译”，黄色警告标明“包含降级兼容宏”；
  3. **下部：生成的 MathSlot 规范简码流**：
     - 通栏等宽只读展示框（高度 70pt），底色 `FIELD`，带微光高亮；
  4. **底部：一键载入动作栏**：
     - `[ ✓ 一键载入并替换编辑器 ]`（电光蓝实心大按钮）：**点击瞬间左侧预览框立即渲染出真实排版**，输入框同步填充简码，光标定位到末尾；
     - `[ 追加到末尾 ]`、`[ 仅复制简码 ]`。

---

### 3.6 Tab 5: 使用指南 (Help)
- **定位**：模块化快捷键图谱与槽位操作心流速查。
- **设计信条**：坚决剔除长篇累赘的说教文字，全采用精炼的**模块化速查卡片网格（2 列响应式布局）**：
  - **Card A: 前缀驱动核心心流**：
    `Tab` 键激活前缀菜单；敲入快捷键进入二级；`Space` 跳出当前槽位；`Alt+←` / `-` 跳转回退；
  - **Card B: 槽位直达导航（Nav Mode）**：
    `Tab j` 或 `Alt j` 开启直达模式；数字 `1~9` / 字母快速瞬移；`Tab / Esc` 退出直达；
  - **Card C: 常用结构语法速查**：
    分式 `/`、上标 `^`、下标 `_`、根号 `Tab f r`、积分 `Tab c i`、矩阵 `Tab m 2`；
  - **Card D: 全局功能快捷键**：
    `Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+Shift+S` 存片段、`F1` 帮助、`F2` 公式库、`F3` 格式库、`F4` 导入 LaTeX。

## 四、 顶栏按钮与一级 Tab 的完美联动机制（Top Bar Synchronization）

顶栏常驻的应用级动作按钮与右侧一级工作区 Tab 实现无缝双向双控：

| 顶栏按钮名称 | 快捷键 | 触发行为 | 对应右侧 Tab | 视觉联动状态 |
| :--- | :--- | :--- | :--- | :--- |
| **公式库** | `F2` / `Alt+2` | 打开/切换至公式库 | `WorkspaceTab::Corpus` | 顶栏按钮亮起 CYAN，右侧分段器切到 [公式库] |
| **格式库** | `F3` / `Alt+3` | 打开/切换至扩展中心 | `WorkspaceTab::Formats` | 顶栏按钮亮起 AMBER，右侧分段器切到 [扩展中心] |
| **⇄ 导入 LaTeX** | `F4` / `Alt+4` | 打开/切换至 LaTeX 导入台 | `WorkspaceTab::LatexImport`| 顶栏按钮亮起 ACCENT，右侧分段器切到 [LaTeX 导入] |
| **帮助** | `F1` / `Alt+5` | 打开/切换至操作指南 | `WorkspaceTab::Help` | 顶栏按钮亮起 TEXT，右侧分段器切到 [使用指南] |
| **符号结构** | `Alt+1` | 回到符号与结构调色板 | `WorkspaceTab::Palette` | 右侧分段器切到 [符号结构] |

> **心流体验原则**：
> 当用户在顶栏点击按钮，界面绝不弹出阻断视线的窗口，而是平滑切换右侧工作区视图。用户输入流完全不被打断，随时可以在左侧输入框继续敲击简码。

## 六、 架构迁移实施步骤（Implementation Roadmap）

1. **第 1 步：状态模型统一（State Consolidation）**：
   在 `MathSlotApp` 中引入 `pub active_tab: WorkspaceTab`，废除 `LibraryModalState` 对 `egui::Window` 的所有依赖，将其持有的表单状态与逻辑方法平移为内联组件状态 `WorkspaceState`。
2. **第 2 步：CentralPanel 分发渲染（CentralPanel Dispatch）**：
   重构 `CentralPanel` 的渲染逻辑：
   - 首先渲染通栏一级分段导航器 `workspace_tab_bar_ui(ui)`；
   - 根据 `self.active_tab`，分别调用：
     - `self.structure_palette_ui(ui, act)` (Tab 1)
     - `self.corpus_workspace_ui(ui, act)` (Tab 2)
     - `self.formats_workspace_ui(ui, act)` (Tab 3)
     - `self.latex_import_workspace_ui(ui, act)` (Tab 4)
     - `self.help_workspace_ui(ui)` (Tab 5)
3. **第 3 步：顶栏按钮与快捷键无缝绑定（Top Bar & Shortcut Wiring）**：
   顶栏中点击“公式库”、“格式库”、“⇄ 导入 LaTeX”、“帮助”直接切换 `self.active_tab`；绑定 `F1`~`F4` 全局快捷键。
4. **第 4 步：表单卡片通栏重构与留白消除（Zero Blank Space Refactor）**：
   全面应用 3 层语义布局，所有输入框与代码框强制采用 `ui.available_width()` 铺满，杜绝任何孤立空白区域。
5. **第 5 步：即时重绘与焦点自愈（Repaint & Focus Healing）**：
   任何载入或插入动作执行后，立即调用 `self.mark_dirty()` 触发全量 LaTeX 刷新，并激活 `self.request_input_focus = true`。
