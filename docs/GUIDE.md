## 1. 工作台界面概览

- **顶部栏**：
  - 中央 **面包屑导航**：实时显示当前光标所处的嵌套路径（如 `公式 › 求和 › 中括号 › 积分·被积式`），点击任意层级可直达，点击 `↑` 跳出一层。
  - 右侧工具按钮：搜索命令与公式库（`Ctrl+K`）、公式库快捷入口、`导入 LaTeX`、层级虚线框开关、跳转模式（`Esc`）、历史记录、清空、窗口置顶（桌面版）、深浅色主题切换、设置、主复制按钮。
- **中央 2D 公式画布**：
  - 所见即所得 KaTeX 渲染，嵌套结构始终以像素级对齐的虚线框清晰区分层级。
  - 支持鼠标点击任意字符定位、拖拽框选、双击选中整个单词/符号。
- **底部快捷工具栏（MathRibbon）**：
  - 左侧 9 个高频一级结构键；右侧 9 个分类二级菜单键。鼠标点击或按 `Tab` 均可触发。
- **底部 LaTeX 源码栏（LatexDock）**：
  - 实时同步规范化出版级 LaTeX 代码；也可直接在此编辑源码并按回车反向同步回 2D 画布。

## 2. 快捷键与二级菜单单键默认

> 默认引导键为 `Tab`（可在「设置」中切换为 `/`）。

### 2.1 一级高频结构（`Tab` + 1 键）

| 快捷键 | 结构 | 输出示例 | 说明 |
| :--- | :--- | :--- | :--- |
| `Tab f` | 分数 | `\frac{a}{b}` | 也可直接输入 `a/b` |
| `Tab r` | 根号（二次/N次合一） | `\sqrt{x}` / `\sqrt[n]{x}` | 根指数留空自动按二次根号渲染 |
| `Tab b` | 上下标 | `x_i^2` / `x_i` / `x^2` | 下标或上标任一留空自动省略 |
| `Tab p` | 自适应圆括号 | `\left(x\right)` | 也可直接输入 `(` |
| `Tab v` | 绝对值 | `\left\|x\right\|` | 含自适应竖线 |
| `Tab i` | 积分（定/不定合一） | `\int_{a}^{b} f(x)\,\mathrm{d}x` / `\int f(x)\,\mathrm{d}x` | 上下限可省 |
| `Tab s` | 求和 | `\sum_{i=1}^{n} a_i` | 上下限可省 |
| `Tab l` | 极限 | `\lim_{x \to 0} f(x)` | 支持前置包裹已有表达式 |
| `Tab e` | 二项式 | `\binom{n}{k}` | 组合数 |

> 提示：原单独上标 `u`、下标 `d` 和 N 次根 `n` 键位已释放，日常请直接输入 `^`、`_` 与 `Tab r`；空出的键位可在 `commands.json` 中自由绑定。

### 2.2 二级菜单单字母即时默认 + 无缝变形

按下 `Tab` + 二级分类字母后，画布会**立即渲染该分类最常用的默认结构**，同时弹出子菜单并标记「默认」：

| 二级入口 | 分类 | 单键默认结构 | 常用第二键示例 |
| :--- | :--- | :--- | :--- |
| `Tab g` | 希腊字母 | `\alpha` | `p` $\pi$ · `t` $\theta$ · `l` $\lambda$ · `s` $\sigma$ · `o` $\omega$ · `w` $\varphi$ · `V` $\vartheta$ · 大写如 `D` $\Delta$ |
| `Tab c` | 微积分 | `\frac{\partial \square}{\partial \square}`（偏导分式） | `a` 不定积分 · `b` 连乘 $\prod$ · `c` 二重积分 $\iint$ · `d` 环路积分 $\oint$ · `e` 三重积分 $\iiint$ · `i` 全导分式 $\frac{\mathrm{d}\square}{\mathrm{d}\square}$ |
| `Tab m` | 矩阵与分段 | `2×2 矩阵` | `b` 3×3 矩阵 · `c` 2×2 行列式 · `d` 分段函数 · `e` 方括号矩阵 · `i`/`j` 省略矩阵/行列式 · `k` 增广矩阵 `[A\|b]` · `l` 行内小矩阵 · `m`/`n` `dcases`/`rcases` |
| `Tab a` | 装饰与字体 | `\hat{x}`（支持自动包裹前字符） | `c` $\vec{x}$ · `f` 范数 $\|x\|$ · `q` 求值线 $F\|_a^b$ · `r` 文本注释 `\text{}`（内部按 `$` 嵌数学槽） · `v` `\boxed{}` · `z`/`A`/`B` 宽帽子/宽波浪/长向量 · `C`/`D`/`E`/`F` `\mathbf`/`\mathcal`/`\mathbb`/`\operatorname` |
| `Tab o` | 运算符号 | `\pm` | `a` $\infty$ · `b` $\to$ · `c` $\partial$ · `d` $\nabla$ · `f` $\times$ · `g` $\cdot$ · `r`/`s`/`t` $\cdots$/$\vdots$/$\ddots$ · `u`/`v` 标注长箭头 $\xrightarrow{}$/$\xleftarrow{}$ · `w`/`x` 宽/细空格 `\quad`/`\,` |
| `Tab x` | 关系符号 | `\approx` | `a` $\equiv$ · `c` $\sim$ · `e` $\Rightarrow$ · `f` $\Leftrightarrow$ · `n` $\le$ · `o` $\ge$ · `p` $\neq$ · `q` $\leftarrow$ · `r` $\leftrightarrow$ · `s`/`t` $\uparrow$/$\downarrow$ · `u` $\hookrightarrow$ |
| `Tab q` | 集合与逻辑 | `\cup` | `b` $\cap$ · `c` $\varnothing$ · `d` $\subset$ · `e` $\exists$ · `i`–`n` $\mathbb{R}/\mathbb{N}/\mathbb{Z}/\mathbb{Q}/\mathbb{C}$ · `o` `\pmod{n}` · `p` 集合构造式 `\{x \mid P\}` · `q`/`r` $\bigcup$/$\bigcap$ · `s` 条件竖线 `\mid` |
| `Tab k` | 自定义结构 | 第 1 条自定义结构 | 按绑定的单字母键插入对应自定义结构 |
| `Tab t` | 复用片段 | 第 1 条片段 | 按绑定的单字母键在光标处插入对应片段 |

**二级菜单内的 4 种后续操作**：
1. **继续输入内容（智能透传）**：若按下的字符不是该菜单的第二键（例如 `Tab m` 后直接按 `1`，`Tab c` 后直接按 `y`，`Tab g` 后按 `+`），自动锁定默认结构并立刻录入该字符。
2. **第二键变形**：按下该菜单有效第二键（如 `Tab m d`），原地无缝替换为目标结构，撤销栈仅记一步。
3. **显式确认**：按 `Enter` / `Space` / `Tab` / 方向键锁定默认结构并关闭弹层。
4. **取消回退**：按 `Esc` 撤销临时默认并退出；按 `Backspace` 撤销临时默认并退回一级菜单。

## 3. 智能缺省（可选槽位）规则

空的可选槽位在光标离开后会自动折叠隐藏，既不产生空框、不计入未填槽位数，也不会输出多余的 `^{}`、`_{}` 或 `[]`：

| 结构 | 可选槽位 | 缺省效果示例 | 事后原地补填方式 |
| :--- | :--- | :--- | :--- |
| 根号 `Tab r` | 根指数 | `\sqrt{x}` ↔ `\sqrt[3]{x}` | 在被开方式内按 `↑`（或 `Shift+Tab`） |
| 积分 `Tab i` | 下限、上限 | `\int f\,\mathrm{d}x` / `\int_D f\,\mathrm{d}x` / `\int_a^b f\,\mathrm{d}x` | 在被积式内按 `↓`（下限）/ `↑`（上限） |
| 求和 `Tab s` / 连乘 `Tab c b` | 下限、上限 | `\sum a_i` / `\sum_{i\in S} a_i` / `\sum_{i=1}^n a_i` | 在主体内按 `↓` / `↑` |
| 二重/三重/环路积分 | 积分区域/路径 | `\iint f` ↔ `\iint_D f` | 在被积式内按 `↓` |
| 上下标 `Tab b` | 下标、上标 | `x` / `x_i` / `x^2` / `x_i^2` | 在主体内按 `↓` / `↑` |
| 代入求值线 `Tab a q` | 下限、上限 | `\left. F\right\|` / `\left. F\right\|_{x=0}` / `\left. F\right\|_a^b` | 在表达式内按 `↓` / `↑` |
| 上/下花括号 `Tab a j`/`k` | 标注 | `\overbrace{x}` / `\underbrace{x}` | 在主体内按 `↑`（上）/ `↓`（下） |

## 4. 自然输入、简写与 LaTeX 命令兼容

### 4.1 独立词与符号简写（非破坏式识别）
- **多字符符号即时简写**（按一次 `Ctrl+Z` 可还原为原字符）：
  - `->` $\to$ · `=>` $\Rightarrow$ · `<=>` $\Leftrightarrow$
  - `<=` $\le$ · `>=` $\ge$ · `!=` $\neq$ · `==` $\equiv$ · `~~` $\approx$ · `~=` $\cong$ · `<<` $\ll$ · `>>` $\gg$
  - `+-` $\pm$ · `-+` $\mp$ · `**` $\cdot$ · `||` $\parallel$
  - `...` $\cdots$ · `:::` $\vdots$
- **独立单词自动识别**（仅在词边界生效，输入 `spin`、`spi`、`pin`、`foo` 绝不会误触发）：
  - 全部 24 个小写 + 11 个大写希腊字母（如 `pi`、`alpha`、`theta`、`Delta`、`Omega`）
  - 数学函数自动直立排版：`sin`, `cos`, `tan`, `ln`, `log`, `exp`, `lim`, `max`, `min`, `det`, `rank`, `tr`, `span` 等
  - 常用符号词：`oo` / `infty` ($\infty$)、`xx` ($\times$)、`partial` ($\partial$)、`nabla` ($\nabla$)、`forall` ($\forall$)、`exists` ($\exists$)、`in` ($\in$)、`vdots` ($\vdots$)、`ddots` ($\ddots$)
  - 出版级直立微分：`dx`, `dt`, `dy`, `dz`, `du`, `dv`, `dr`, `dtheta` 等自动渲染并导出为 `\,\mathrm{d}x`

### 4.2 LaTeX 原生命令实时兼容
如果习惯直接打 LaTeX 命令（在默认引导键为 `Tab` 或 `/` 时）：
- **结构命令**：输入 `\int`、`\sum`、`\prod`、`\lim`、`\iint`、`\iiint`、`\oint`、`\frac`、`\sqrt`、`\binom`、`\vec`、`\hat`、`\bar`、`\tilde`、`\overline`、`\underline`、`\overbrace`、`\underbrace`、`\pmatrix`、`\bmatrix`、`\vmatrix`、`\cases` 后，按 **`Space`** 或 **`Enter`** 立即转为 2D 交互结构并定位到首槽。
- **定界符直入触发**：
  - `\int_` / `\sum_` / `\lim_` 直接展开并落入**下限**；`\int^` / `\sum^` 直接落入**上限**
  - `\sqrt[` 直接展开并落入**根指数**；`\sqrt{` 直接落入**被开方式**
  - `\frac{` / `\vec{` / `\hat{` 直接展开并落入**首槽**
- **符号与上下标连写**：输入 `\alpha_1`、`\pi^2` 自动展开为 $\alpha_1$、$\pi^2$；输入 `\vdots `、`\ddots `、`\infty ` 立即展开为对应符号。

### 4.3 自动向后包裹
在字母/符号后直接触发装饰命令（如先打 `x` 再按 `Tab a c`），自动将前一个原子包裹为 `\vec{x}`，无需手动选中。

## 5. 动态矩阵、行列式与省略元素矩阵

- **四方向快速增行列**（光标在矩阵/行列式/分段函数内）：
  - `Shift + ↓`：下方加一行
  - `Shift + ↑`：上方加一行
  - `Shift + →`：右侧加一列
  - `Shift + ←`：左侧加一列
  - 也可使用单元格下方的浮动控制条（`+行` / `−行` / `+列` / `−列`）或 `Alt+Enter` / `Alt+Shift+Enter`。
- **省略元素矩阵与 n 阶行列式**：
  - `Tab m i`：4×4 圆括号省略矩阵（预填 `⋯`、`⋮`、`⋱`，可任意增删行列）
  - `Tab m j`：4×4 单竖线省略行列式（直接用于范德蒙德行列式等 n 阶行列式）
  - 单元格内也可随时用 `...`（`⋯`）、`:::` 或 `vdots`（`⋮`）、`ddots`（`⋱`）输入省略号。
  - 预置公式库「线性代数」中已内置 **n 阶范德蒙德行列式 (Vandermonde)**，搜索即可一键载入。

## 6. 层级导航与 `Esc` 分层字母跳转

当公式嵌套多层时（例如傅里叶级数、积分内嵌分式）：
1. 按 **`Esc`**（或 `Tab j`）进入跳转模式，当前作用域内的每个子槽和独立文本项（如两个积分中间的普通数字 `+ 42 +`）上方/下方会出现字母角标：
   - **普通角标（如 `b`）**：按 `b` 直接跳入并退出跳转模式。
   - **复合角标（带 `+` 号，如 `d+`）**：表示内部还有嵌套结构；按 `d` 展开其子层级继续精确定位，按 `Backspace` 或 `↑` 返回上一层级。
2. 跳转模式快捷导航：
   - `←` / `→` 切换高亮目标，`↓` 展开复合目标，`Enter` 确认
   - `.` / `;` 跳到当前层级末尾，`0` 跳到当前层级开头
   - `-` 跳回上一个光标位置（同编辑态 `Alt + ←`），`+` 前进（同 `Alt + →`）

## 7. 槽位填空顺序与个性化设置

打开右上角 **设置（⚙）** 可按习惯配置：
- **外观**：跟随系统 / 浅色 / 深色
- **默认输出格式**：纯 LaTeX / `$…$` / `$$…$$` / ` ```latex `
- **快捷键引导键**：`Tab` / `/`（旧配置中的 `\` 会自动迁移为 `Tab`，保留 `\` 用于原生 LaTeX 命令输入）
- **槽位填空顺序**：
  - 一键切换「标准顺序」或「中文书写习惯」（如分数先分母后分子「三分之二」）
  - 支持对分数、根号、积分/求和、极限、上下标、二项式分别微调
- **输入开关**：独立词简写、括号自动补全、`/` 自动分数、`^`/`_` 自动上下标、空格跳出上下标、`;` 跳下一槽、层级虚线框显示、底部 LaTeX 源码栏显示。

## 8. 自定义结构、复用片段与历史记录

- **自定义结构（`Ctrl+K → 自定义结构` 或 `Tab k`）**：
  - 用 `$1`、`$2` 定义任意槽位模板（如 `\mathbb{E}\left[$1\right]`），可绑定 `Tab k <字母>` 快捷键及自动展开简写（如输入 `EE` 秒出数学期望），自带快捷键冲突校验与面包屑显示。
- **复用片段（底部源码栏书签图标或 `Tab t`）**：
  - 将当前画布公式保存为命名片段，绑定单字母后按 `Tab t <字母>` 即可在任意光标处插入，若含空槽会自动跳入首个空槽。
- **历史记录（顶部时钟图标）**：
  - 复制、提交或清空非空公式时自动保留最近 40 条历史，一键回溯载入。

## 9. 开放外部公式库与命令库（无需重新编译）

MathSlot 支持在软件内直接管理，也支持直接用任意文本编辑器修改外部 JSON 文件并热重载：

### 配置文件位置（桌面版首次启动自动生成）
- **Linux**：`~/.config/io.mathslot.desktop/presets.json` 与 `~/.config/io.mathslot.desktop/commands.json`
- **macOS**：`~/Library/Application Support/io.mathslot.desktop/`
- **Windows**：`%APPDATA%\io.mathslot.desktop\`
- **快捷入口**：在 `Ctrl+K` 面板右上角点击 **`目录`** / **`重载`**，或在 **设置 → 外部公式库与命令库文件** 点击 **`打开配置目录`** / **`重新加载文件`** / **`恢复默认`**。

### `presets.json` 格式示例
```json
[
  {
    "id": "my-parseval",
    "name": "帕塞瓦尔恒等式",
    "category": "考研高数",
    "source": "\\frac{1}{\\pi}\\int_{-\\pi}^{\\pi} [f(x)]^2\\,\\mathrm{d}x = \\frac{a_0^2}{2} + \\sum_{n=1}^{\\infty}(a_n^2+b_n^2)",
    "desc": "傅里叶级数能量守恒公式"
  },
  {
    "id": "preset-quadratic-formula",
    "disabled": true
  }
]
```

### `commands.json` 格式示例
```json
[
  {
    "id": "laplace_transform",
    "label": "拉普拉斯变换",
    "category": "calculus",
    "keys": ["c", "z"],
    "slots": ["原函数"],
    "latex": "\\mathcal{L}\\left\\{$1\\right\\}"
  },
  {
    "id": "my_vec_u",
    "label": "单位向量",
    "category": "structure",
    "keys": ["u"],
    "slots": ["向量"],
    "latex": "\\hat{\\mathbf{$1}}"
  }
]
```

- **新增条目**：填写新的 `id` 即可；新增的 `category` 分类会自动生成筛选胶囊。
- **覆盖内置条目**：使用与内置条目相同的 `id` 即可覆盖名称、模板或快捷键。
- **隐藏内置条目**：写入 `{ "id": "<内置id>", "disabled": true }`。
- **安全容错**：文件采用原子写入（`.tmp` + rename），即使手动改错 JSON 语法也不会崩溃，系统会提示并自动安全回退。

## 10. 多行对齐与多格式导出（LaTeX / Word / PNG）

- **多行对齐公式**：在顶层按 `Enter` 换行；若任意行包含关系符（`=`、`\sim`、`\le`、`\ge` 等），导出时自动在每行首个关系符前插入 `&` 并生成出版级 `\begin{aligned} ... \end{aligned}`。
- **Word 公式（MathML）**：点击底部 `Word` 按钮，通过 KaTeX 生成标准 MathML 写入剪贴板，直接在 Word / WPS / LibreOffice 中粘贴为原生可编辑公式。
- **高清 PNG 图片**：点击底部 `PNG` 按钮，渲染 3× DPI 高清透明底 PNG 直接写入系统图片剪贴板，贴入聊天软件、PPT 或网页文档均清晰锐利。

## 11. Obsidian 插件专享能力

- **零 WASM、秒开轻量**：纯前端打包为 `main.js` + `styles.css` + `manifest.json`，无任何二进制依赖。
- **光标处公式原地编辑**：将光标置于笔记内任意 `$...$` 行内公式或跨行 `$$...$$` 块级公式中，打开 MathSlot 即可自动载入该公式，编辑完按 `Ctrl + Enter` 自动原地替换原公式范围并保留原定界符格式。
- **自定义数据同步**：所有设置、片段、自定义结构、历史记录与自定义公式/命令库均自动保存在 Obsidian 插件 `data.json` 中，可随 Vault 同步。
